# jcsoftdev/homebrew-tap

Homebrew formulae for [jcsoftdev](https://github.com/jcsoftdev) projects.

```sh
brew install jcsoftdev/tap/project-brain
```

## Formulae

| Formula | Source | Description |
|---------|--------|-------------|
| `project-brain` | [jcsoftdev/project-brain](https://github.com/jcsoftdev/project-brain) | Local-first MCP server for codebase knowledge: semantic search plus a call graph |

## How formulae get here

`Formula/project-brain.rb` is generated by `scripts/gen-packages.ts` in the
project-brain repo and published by its release workflow. Do not edit it by
hand — the next release overwrites it.
